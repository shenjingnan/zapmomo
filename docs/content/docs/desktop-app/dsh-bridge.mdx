# deepseek-harness 集成（dsh 桥）

桌宠实时感知 [deepseek-harness](https://github.com/deepseek-ai/deepseek-harness)（dsh）任务状态：任务开始 / 完成 / 失败 / 中断时，Live2D 角色以文字气泡 + 语音播报。

## 安装（推荐：应用内一键安装）

打开 ZapMomo 主菜单「**插件集成**」，dsh 集成卡片会自动检测本地环境：

- 检测到 dsh 且插件未安装 → 点「**一键安装**」，应用代跑安装命令并显示进度；
- 自动定位失败 → 点「选择 dsh 可执行文件」手动指认，或复制命令回终端执行；
- 已安装但显示「未激活」→ 复制修复命令重跑一次即可；
- 插件在线后徽章翻为「**在线**」，此时在 dsh 里发起任务，桌宠实时播报。

状态说明：插件每 15 秒向 ZapMomo 发一次心跳；「已激活 · 等待在线」通常意味着 `dsh web`
尚未启动或安装后未重启——启动 / 重启 `dsh web` 后 45 秒内自动翻绿。

## 安装（手动：终端命令）

```bash
dsh plugin --profile web add @zapmomo-ai/dsh-plugin
```

装完重启 `dsh web` 即生效。dsh 桥默认已启用，无需额外配置。

## 验证

插件集成页点「测试播报」，桌宠弹气泡并播报即链路通；之后 dsh 任务开始 / 结束时桌宠会自动播报。

## 配置（可选）

插件集成页的 dsh 卡片内可开关语音播报、是否写入对话记录；也可编辑 `~/.zapmomo/settings.toml` 的 `[dsh]` 段：

| 配置项 | 缺省 | 说明 |
| --- | --- | --- |
| `enabled` | `true` | 是否启用桥服务 |
| `port` | `0` | 监听端口，`0` = 随机 |
| `voice_enabled` | `true` | 事件是否语音播报（语音会话中只出气泡） |
| `record_to_history` | `true` | 事件是否写入对话记录 |
